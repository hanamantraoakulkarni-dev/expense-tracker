# 💰 Expense Tracker

## About the Project

A simple expense tracking web application built using Python and Flask. It helps users record, manage and monitor their daily expenses.

## Technologies Used

* Python
* Flask
* HTML
* CSS

## Features

* Add expenses
* Remove expenses
* Calculate total expenses
* Count recorded expenses
* Find the largest expense

## How to Run

1. Install Python.
2. Install Flask using `pip install flask`.
3. Run `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser.
